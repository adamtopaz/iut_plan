# Reusable arithmetic and anabelian geometry results

The plan aims to deliver useful mathematics before the final IUT integration. **★ REUSABLE** means a result has a mathematical interface and applications beyond IUT; it does not assert that mathlib has already accepted, or will accept, a particular implementation. The milestones below are result-level release targets. Each should have its own conventional statement, proof, functoriality lemmas and examples, without importing Hodge theaters or Theorem 3.11.

A milestone is complete when its Lean proof uses only proved prerequisites and standard Lean axioms, its mathematical interpretation has been independently checked, and its declarations build against the pinned dependency versions. Interface prototypes with unproved laws are useful for parallel development but do not count as completed theorem releases. [Contribution standards](../CONTRIBUTING.md) govern the detailed checks.

## How to make these releases parallelizable

1. Freeze a small **interface agreement** for each boundary: base-field topology; geometric curves and covers; profinite outer maps; continuous coefficient modules; Tate twists; and normalization conventions. A team may prototype against that agreement while another proves its implementation, but integration requires the bridge theorems.
2. Split **a theorem from its interpretation**. For example, one team proves the abstract Galois-category result already in mathlib is usable; another proves the finite-étale category satisfies its axioms; a third develops the arithmetic exact sequence against that category. Only the geometric bridge justifies calling the result the scheme's `π₁`.
3. Publish conventional lemmas incrementally. Do not make a local logarithm lemma import Frobenioids, or make Riemann–Roch import anabelian reconstruction. The [package DAG](../graphs/work-packages.md) states the eventual proof order; interface design and source auditing start earlier.
4. Use the first theorem releases to measure actual effort: missing API lemmas, declaration/build count, independent review work and bridge failures. Pages or books are not uniform units of work, so this plan assigns no unsupported person-year estimate.
5. Complete the IUT constructions and compatibility packages with all these interfaces proved, then integrate [P31: Theorem 3.11](../work-packages/31-theorem-3-11.md) **last**. A theorem whose assumptions contain the unproved comparison laws is a conditional prototype, not the completed target.
