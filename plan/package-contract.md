# Stable package identifiers and dependency convention

Arrows run **prerequisite → consumer**. Package dependencies concern completed proofs and the interpretation bridges they export; interface design and definition work can start earlier in parallel.

Package IDs are stable so source cards, team assignments and dependency graphs refer to the same output. The final theorem is P31 and is the unique final integration sink. Audits are tracked separately and must not become disguised mathematical axioms.
