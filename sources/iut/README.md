# IUT construction sources

| Paper | Formalization slice | Owning packages |
|---|---|---|
| [IUT I](iut-i.md) | Initial data, strips, labels, bridges, processions, theaters and reconstruction | P21–P22 |
| [IUT II](iut-ii.md) | Local theta evaluation/synchronization, global Kummer gluing, pilots and horizontal links | P23–P24 |
| [IUT III](iut-iii.md) | Log-links/coricity, theta monoids, measured packets, LGP constructions, global Kummer, complete compatibility and final theorem | P25–P31 |

These sources depend on the independently useful [foundational](../foundations/README.md) and [anabelian](../anabelian/README.md) libraries. Definitions can be designed early, but acceptance of an IUT reconstruction statement requires its underlying proof and interpretation bridge.
