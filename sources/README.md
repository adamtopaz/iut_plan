# Papers, books and precise formalization targets

This catalogue links every source card in the plan. Each card names selected results and their owning packages, distinguishes audited targets from caller-only or proposed proof inputs, and records source-version/correction work. Entire books are not additive formalization requirements.

**★ REUSABLE:** conventional mathematics/API with applications beyond IUT. **◇ IUT SUPPORT:** specialized substrate. **IUT SPECIFIC:** IUT construction/compatibility. These labels apply to exports, not blanket reputational judgments about a source.

Start with the [source graph](../graphs/sources.md), then choose a numbered deliverable in the [package directory](../work-packages/README.md). The [roadmap](../plan/roadmap.md) and [staged interfaces](../plan/interfaces.md) explain parallel handoffs.

## Source lock and completion

A source card is a work specification, not an imported axiom. The [audit gates](../tracking/audit-gates.md) own recursive proof closure, both known theorem-number mismatches, proof-source choices, and correction integration. A source may export a useful narrow theorem before a stronger/general version is completed. Retained alternative references need proved compatibility with the consumer; boundary/counterexample references do not become positive prerequisites by being listed.
